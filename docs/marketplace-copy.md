# Aozora导演系统——简单好用的生图插件

## 商城卡片短句

只需要设定目标，导演会帮你画出心仪的画面。

## 简介

只需要设定目标，导演会帮你画出心仪的画面。

你只需设定想看的画面目标，Aozora 会结合当前剧情、人物档案与画风，整理镜头、角色特征和提示词，让 CG 自然跟上故事。

### 🎬 剧情生图与人物延续

- 可随着剧情生成 CG，也能给对话后的情节补图。
- 支持人物登记、外貌特征与服装管理，帮助已登记人物在后续画面中延续外观与穿着。

### ✨ NAI 4.5 FULL 主力优化

- 以 NAI 4.5 FULL 为主力模型，默认使用经过测试的日系半写实游戏 CG 画风，并对人物信息、镜头表达和提示词编排等出图环节做了大量针对性优化。

### 🖼 图生图与动态 CG

- 基于已有图片继续调整、细化画面。
- 使用图生图链路生成简单动态 CG。

### 🎨 四套代表性画风

- 内置四套代表性画风：日系半写实游戏 CG、动漫游戏 CG、欧美动漫 CG、欧美半写实 CG。
- 可自行创建，也支持导入、导出，方便与社区交流分享。

### 📖 历史阅读

- 按轮查看正文与对应 CG。
- 已隐藏的历史回复也能读取，可以像看小说一样从头连贯回读剧情。

### ⚠️ 当前适配范围与已知限制

- 图生图与动态功能目前仅支持 NAI 4.5 FULL 链路；四套内置画风也主要针对该模型优化，在此模型下效果较好，其他模型的表现可能不同。
- 出图效果仍在持续迭代，我们会收集使用意见并继续改进，欢迎反馈。

### 🔌 其他模型兼容

- 其他模型也可复用人物特征延续、服装状态、剧情取景和通用导演规则，并按对应模型格式组织提示词。
- 主力模型 API 由插件管理；通用生图模式接入 Tavo 原生生图链路。
- 后续也会继续寻找合适模型做专项优化。
